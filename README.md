One line an AI agent prints the instant it breaks production: a brutally honest error message. The agent "fixed" the 500 errors by answering 200 with an empty page — the errors are gone, and so is the site. Written for make.fun's "Break Production, Own It" bounty ($2 in USDC).

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=out python3 main.py`). See `entry.txt` for the line itself and `METHODOLOGY.md` for how it was chosen.
